### 3.2 服務介紹

**計畫目的**
提供具特殊醫療需求的兒童及青少年（以下簡稱特需兒少）整合性的眼科醫療服務，保障其視覺健康權及平等就醫權。

**計畫簡介**
藉由醫療團隊提供專屬眼科檢查及視覺訓練，提升特需兒少視覺功能、學習表現與生活適應，同時減輕家長照護負擔。

**雙重支持**

*特需兒少可獲得的幫助：*
1. 友善的視覺檢查：使用適合的評估方式，提升診斷準確度
2. 提升視覺功能：個別化訓練與治療，改善視力、眼球控制與視覺處理能力
3. 促進學習與生活適應：提升專注力、閱讀能力及日常活動表現，增強自信心
4. 跨專業照護：結合眼科醫師、視光師、職能治療師等專業團隊

*家長可獲得的幫助：*
1. 專業評估與個別化建議：依特需兒少需求提供專屬視覺檢查與治療建議
2. 降低兒少就醫抗拒：採用友善評估方式，減少檢查時的壓力與不適感
3. 提升孩子生活品質：改善視覺功能，有助學習、專注力與日常活動
4. 減輕家長負擔：提供豐富的衛教與資源，協助家長照護特需兒少的視覺健康

**收案對象**
身心障礙或發展遲緩的兒童及青少年，且無法配合一般眼科門診診療者。

**收案條件**
符合任一特殊情形 **且** 任一特定生理條件者：

| 特殊情形 | 特定生理條件 |
|----------|-------------|
| 難以配合一般眼科檢查 | 腦性麻痺、中度以上肢體障礙、心智障礙、頑固性癲癇、多重障礙（同時具有2種以上） |
| 無法於一般眼科門診測得視覺狀況 | 中度以上視覺障礙 |
| 可透過跨專業團隊協助改善功能性表現 | 因罕見疾病而導致身心功能障礙 |

**服務內容（4 象限）**

| 象限 | 內容 |
|------|------|
| 跨專業、整合性醫療團隊 | 眼科專科醫師、職能治療師、驗光師 |
| 符合特需兒少的環境設備 | 專屬門診與空間、友善無障礙環境、特殊設施與設備 |
| 整合性眼科評估檢查服務 | 因應個案需求提供度數、斜視、視野等檢查及聯合評估 |
| 基礎/進階視覺復能服務 | 一對一治療、訓練、衛教等醫療服務 |

**申請服務流程（5 步驟）**

```
1. 聯絡合作醫院
   → 填寫服務申請單（早療聯合評估報告、醫療檢查報告、身心障礙手冊等）

2. 安排專屬門診及聯合評估
   → 符合收案條件者安排就診
   → 不符合者，持續在一般門診追蹤

3. 執行聯合評估
   → 視需求安排追蹤或復能

4. 完成追蹤、復能

5. 結案
```

### 3.3 視覺復能

**定義**
依個案的問題與需求，發展個別化代償性和矯治性復能，以成就個體或其家庭發展、學習、生活等自主性。
- 代償性：輔具協助、策略學習
- 矯治性：眼球動作訓練、視覺刺激訓練、知覺學習等

**6 大方案**

| 方案名稱 | 適用對象 | 說明 |
|----------|----------|------|
| 眼球動作訓練方案 | 閱讀/抓握/轉頭困難 | 眼球追蹤、凝視穩定與跳視訓練 |
| 擁擠效應方案 | 低視力/腦性視覺障礙 | 個別化視覺辨識策略、知覺學習訓練 |
| 眼科情境適應方案 | 就診焦慮特需兒 | 事前練習、視覺結構化指引、環境調整 |
| Perception Learning 方案 | 視力發展遲緩 | Oddball 訓練活化大腦視覺處理 |
| 視覺刺激方案 | 腦性視覺障礙低視力 | 高對比、燈光導引、動態色彩刺激 |
| Little Room（視覺小屋）方案 | 重度視覺/多重障礙 | 早期視覺探索空間，感官整合訓練 |

## 四、多語系規格

| 語言 | 觸發條件 | 備註 |
|------|----------|------|
| 繁體中文 `zh-TW` | `zh-TW`、`zh-HK`、`zh` 開頭 | 預設語言 |
| 英文 `en` | `en-*` 及其他所有語言 | Fallback |

**實作方式**
- 偵測：`navigator.language`（瀏覽器語系）
- 右上角 Language Toggle 按鈕手動切換（顯示 `EN` / `中`）
- URL 不變，純 JS 切換（`data-i18n` 屬性 + `innerHTML` 更新）
